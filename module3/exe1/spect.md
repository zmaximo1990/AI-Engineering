Ejercicio

Como arquitecto de IA, debes evaluar la capacidad de un modelo de embeddings para discernir entre relevancia semántica y coincidencia de palabras clave.

- Selecciona un conjunto de 5 oraciones que traten sobre el mismo concepto técnico (ej: "Despliegue de microservicios") pero usen vocabulario totalmente distinto.
- Incluye 2 oraciones "trampa" que compartan palabras clave pero tengan significados opuestos o irrelevantes (ej: "El servicio de micro-limpieza es excelente").
- Investiga cómo usarías la librería scikit-learn en Python para calcular la Similitud Coseno entre dos vectores numéricos.
- Diseña un diagrama de flujo simple de un proceso de búsqueda semántica: desde que el usuario ingresa una query hasta que el sistema devuelve el documento más parecido.

Entregable: Un documento PDF que contenga el análisis de las oraciones, el fragmento de código (pseudocódigo o Python) para el cálculo de similitud y el diagrama de flujo del proceso.
