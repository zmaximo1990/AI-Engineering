Escenario: Sistema de Análisis de Sentimiento y Respuesta Automatizada

Eres el arquitecto de IA de una empresa de e-commerce. Debes proponer el diseño de una topología jerárquica para un sistema que recibe quejas de clientes por Twitter, analiza el sentimiento, verifica el estado del pedido en una base de datos y genera una respuesta personalizada.

Identificación de Agentes: Define al menos 3 agentes especialistas y un supervisor.
Definición de Responsabilidades: Para cada agente, describe brevemente qué hace y qué herramientas (tools) necesitaría.
Diagrama de Flujo Lógico: Describe el paso a paso de cómo fluye la información desde que llega el Tweet hasta que se envía la respuesta.
Justificación de Topología: Explica por qué elegiste una topología jerárquica en lugar de una cooperativa para este caso específico de servicio al cliente.
Entrega: Un documento PDF o Markdown con la propuesta arquitectónica detallada.
